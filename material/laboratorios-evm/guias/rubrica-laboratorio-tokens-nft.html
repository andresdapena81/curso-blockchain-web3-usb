CÓMO FUNCIONA ESTE LABORATORIO

Todo corre en la red local de Hardhat: no se necesita ETH, ni red pública, ni IPFS. El trabajo es completar los // TODO de cada contrato hasta que las pruebas pasen. Lo verifican ustedes mismos con npm run ficha (Lab 1) y npm run diploma (Lab 2). No se modifican los archivos de test/: son la calificación. La parte automática (58 de 100 puntos) es objetiva: la prueba pasa o no pasa.

05

Uso de IA y honestidad

Pueden usar asistentes de IA, pero deben declararlo. El laboratorio no se gana pegando una respuesta que no entienden: la parte de argumento y la reflexión miden su criterio. Entregar algo que no comprenden —aunque la prueba pase— y no poder sostener el porqué anula los puntos de argumento y reflexión.
